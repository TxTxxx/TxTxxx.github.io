<section class="deep-section" id="scope">
  <span class="section-index">01 / SCOPE</span>
  <h2>少生成几个 token，仍输出完整动作段</h2>
  <p>机器人动作逐维离散化后，自回归生成序列可能很长。以 7 维动作设置为例，OAT 将 32 步动作压缩为最多 8 个 token，并训练短前缀重建同样长的动作段：前几个 token 提供粗略轨迹，后续 token 补充细节。它延续了 FAST 所涉及的动作编码问题，适合用来理解 VLA 的动作输出接口。</p>
  <p>本文由 Codex 整理，依据 <a href="https://arxiv.org/abs/2602.04215v2" target="_blank" rel="noreferrer">2026-02-11 的 arXiv v2</a>。论文首发于 2026-02-04，已由 <a href="https://www.roboticsproceedings.org/rss22/p075.html" target="_blank" rel="noreferrer">RSS 2026 收录</a>，入围 <a href="https://roboticsconference.org/program/awards/" target="_blank" rel="noreferrer">Outstanding Paper Award</a>，并非获奖论文。下文数字均为原版报告值，未独立复现。</p>
</section>

<section class="deep-section" id="method">
  <span class="section-index">02 / METHOD</span>
  <h2>用前缀重建训练 token 的先后层次</h2>
  <figure class="paper-figure">
    <a href="/images/paper-radar/2026-09-13-oat/ordered-token-prefix-training.png" target="_blank" rel="noreferrer"><img src="/images/paper-radar/2026-09-13-oat/ordered-token-prefix-training.png" alt="Figure 3：动作与寄存器进入 Transformer，寄存器经 FSQ 离散化；嵌套丢弃保留前缀、遮蔽后缀，解码器仍重建完整动作。右侧自回归策略逐个生成 token，追加 token 细化整条轨迹" loading="lazy" /></a>
    <figcaption>Figure 3 · <a href="https://arxiv.org/pdf/2602.04215v2#page=4" target="_blank" rel="noreferrer">arXiv v2 PDF 文件第 4 页</a>。Chaoqi Liu、Xiaoshen Han、Jiawei Gao、Yue Zhao、Haonan Chen、Yilun Du，<em>OAT: Ordered Action Tokenization</em>。300 dpi 渲染，裁去页边和图外文字，保留完整图内内容。依据 <a href="https://arxiv.org/abs/2602.04215v2" target="_blank" rel="noreferrer">arXiv 许可声明</a>，本图按 <a href="https://creativecommons.org/licenses/by/4.0/" target="_blank" rel="noreferrer">CC BY 4.0</a> 使用。点击查看高清版。</figcaption>
  </figure>
  <p>先训练动作编解码器。可学习的 registers（寄存器向量）汇总整段动作；每个寄存器能看全部动作和更早的寄存器。其输出经有限标量量化（FSQ）变成离散 token。这里的顺序描述信息层次，不对应机器人执行的时间步。</p>
  <p>关键训练操作是 nested dropout：随机保留前 K 个 token、遮蔽其余 token，解码器仍重建整段动作，以均方误差优化。后部信息不能回流到前部寄存器，短前缀必须承担重建任务。图中用 4 个 token 示意，主要策略实验最多使用 8 个。</p>
  <p>随后训练视觉策略，依据观测自回归预测动作 token，再由解码器一次还原 32 步动作，执行前 16 步后重新规划。新增机制是让压缩后的前缀具有可用的重建结构；“任意前缀可解码”只保证能产生连续动作输出，不保证动作安全或任务成功。</p>
</section>

<section class="deep-section" id="ablation">
  <span class="section-index">03 / ABLATION</span>
  <h2>去掉嵌套丢弃后，完整序列成绩也下降</h2>
  <figure class="paper-figure">

  </figure>
  <p>OAT× 只去掉嵌套丢弃，其他架构和训练设置保持不变。RoboMimic 上，8 token 策略成功率从 73.1% 降至 61.1%。这支持前缀重建训练的作用，但尚不能把“有序性”与这种训练目标的其他正则化作用完全分开。</p>
  <p>四套仿真基准共 21 个任务，每个任务以 5 组随机种子各评估 50 次。基线包括 FAST、QueST 和 Diffusion Policy，使用小型 Transformer 策略；这些比较不能直接外推到大型预训练 VLA。</p>
  <p>截至 2026-09-13，<a href="https://github.com/Chaoqi-LIU/oat#known-issue-libero-reset-ordering" target="_blank" rel="noreferrer">原代码仓库明确警告</a>：LIBERO 在物体静置前获取初始观测，返回的图像和机器人状态与静置后的场景不一致。当前说明未给出修正后对应成绩，不能据此量化影响或认定排名翻转；表中的 LIBERO 数字需要修正复测。</p>
</section>

<section class="deep-section" id="real-world">
  <span class="section-index">04 / REAL WORLD</span>
  <h2>真机各测 20 次，短前缀会损失精度</h2>
  <p><a href="https://arxiv.org/pdf/2602.04215v2#page=8" target="_blank" rel="noreferrer">Table V</a>在 ARX-5 单臂上测试放球与叠杯，每任务收集 200 条遥操作示范。OAT 8 token 各成功 16/20 次，Diffusion Policy 分别为 14/20、11/20；OAT 4 token 则为 13/20、12/20。样本较少，放球仅多成功两次，不能宣称稳定的普遍优势。</p>
  <p><a href="https://arxiv.org/pdf/2602.04215v2#page=7" target="_blank" rel="noreferrer">Table II</a>的 LIBERO 配置下，A100 上 8 token 推理为 27.4 ms，4 token 为 17.4 ms。这是策略推理耗时，不是完整机器人控制周期；缩短序列需要同时检查动作精度。</p>
</section>
