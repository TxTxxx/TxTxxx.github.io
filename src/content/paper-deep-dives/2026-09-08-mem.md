<section class="deep-section" id="verdict">
  <span class="section-index">01 / SCOPE</span>
  <h2>记住操作细节，也记住任务进度</h2>
  <p>MEM 为 π0.6 加入两种记忆：短期视频保存动作和遮挡信息，长期文字记录已完成的步骤。真机实验涉及最长约 15 分钟的操作，但不代表每次都能完整完成任务。本文由 Codex 整理，依据 <a href="https://arxiv.org/abs/2603.03596" target="_blank" rel="noreferrer">2026-03-04 首发、03-08 更新的 arXiv v2</a>；截至本期核验，按预印本介绍，不标注未经确认的会议接收。</p>
</section>

<section class="deep-section" id="problem">
  <span class="section-index">02 / PROBLEM</span>
  <h2>单帧观察缺少两类历史</h2>
  <p>机器人拿取物体时，手臂可能挡住目标；清理厨房时，当前画面又不一定能说明哪块台面已经擦过。前者需要近期细节，后者需要跨步骤的语义状态。把整段视频送入 VLA 会增加计算和延迟；只保留文字，则难以精确描述运动细节。</p>
</section>

<section class="deep-section" id="method">
  <span class="section-index">03 / METHOD</span>
  <h2>高层更新摘要，低层读取短视频</h2>
  <figure class="paper-figure">
    <a href="/images/paper-radar/2026-09-08-mem/multiscale-memory-architecture.png" target="_blank" rel="noreferrer"><img src="/images/paper-radar/2026-09-08-mem/multiscale-memory-architecture.png" alt="Figure 2：左侧高层接收目标、观察与旧文字记忆，输出新记忆和语言子任务；右侧低层通过视频编码器和动作专家执行子任务" loading="lazy" /></a>
    <figcaption>Figure 2 · <a href="https://arxiv.org/pdf/2603.03596v2#page=4" target="_blank" rel="noreferrer">PDF 文件第 4 页</a>。来源：Marcel Torne、Karl Pertsch 等，<em>MEM: Multi-Scale Embodied Memory for Vision Language Action Models</em>，arXiv v2。由原 PDF 渲染裁出完整图区，未改变图内内容；依 <a href="https://arxiv.org/abs/2603.03596v2" target="_blank" rel="noreferrer">arXiv 所列许可</a> <a href="https://creativecommons.org/licenses/by/4.0/" target="_blank" rel="noreferrer">CC BY 4.0</a> 使用。点击图片查看高清版。</figcaption>
  </figure>
  <p>先看左侧粉色模块：高层根据任务、观察和旧摘要 m<sub>t</sub>，预测新摘要 m<sub>t+1</sub> 与下一条子任务。训练时，作者用现成 LLM 处理子任务标注及成功／失败信息，生成压缩摘要作为监督。上线后由训练好的策略更新记忆，不是在每个控制步另调一次外部 LLM。</p>
  <p>再沿虚线看右侧：低层接收语言子任务和近期观察，生成连续动作块。视频编码器在 ViT 每第四层加入因果时间注意力，让同一图块聚合过去信息；送入 VLM 的仍只有当前时刻的图块表示，控制视觉 token 数量。实验中观察记忆最多扩展至 18 帧、54 秒；15 分钟任务依赖文字摘要，不能把两者混为同一个视频窗口。</p>
  <p>摘要还会压缩冗余历史。直接拼接过去指令时，机器人反复失败会产生训练示范中少见的重复序列；学习更新摘要有助于减轻这种分布偏移，但摘要本身仍可能漏记或误记。</p>
</section>

<section class="deep-section" id="evidence">
  <span class="section-index">04 / EVIDENCE</span>
  <h2>消融支持组合记忆，纵轴是任务进度</h2>
  <figure class="paper-figure">
    <a href="/images/paper-radar/2026-09-08-mem/long-horizon-memory-ablation.png" target="_blank" rel="noreferrer"><img src="/images/paper-radar/2026-09-08-mem/long-horizon-memory-ablation.png" alt="Figure 6：菜谱准备、厨房清理及平均任务进度；黄色 MEM 与无记忆、仅视频、仅文字和直接拼接文字加视频四种对照，保留标准误差条" loading="lazy" /></a>
    <figcaption>Figure 6 · <a href="https://arxiv.org/pdf/2603.03596v2#page=6" target="_blank" rel="noreferrer">PDF 文件第 6 页</a>。来源：Marcel Torne、Karl Pertsch 等，<em>MEM: Multi-Scale Embodied Memory for Vision Language Action Models</em>，arXiv v2。完整保留图例、子图、坐标与误差条；由原 PDF 渲染裁切，依 <a href="https://arxiv.org/abs/2603.03596v2" target="_blank" rel="noreferrer">arXiv 所列许可</a> <a href="https://creativecommons.org/licenses/by/4.0/" target="_blank" rel="noreferrer">CC BY 4.0</a> 使用。点击图片查看高清版。</figcaption>
  </figure>
  <p>比较黄色 MEM 与绿、灰和蓝色对照：两类长任务中，组合记忆的平均进度均更高；仅增加历史输入并不保证改善表现。纵轴按完成子步骤计分，例如取出指定物品或完成清洁步骤，不能读成整条任务成功率；图中为均值 ± 标准误差，未给出柱顶精确数值，本导读不反推小数。</p>
  <p>评测为每策略、任务或菜谱 10 次运行。菜谱准备训练覆盖 42 个菜谱，测试取其中 5 个，换到未见厨房和物品：这是环境与物品泛化，不是未见菜谱的零样本测试。评分细则见 <a href="https://arxiv.org/pdf/2603.03596v2#page=13" target="_blank" rel="noreferrer">附录 B（PDF 文件第 13 页起）</a>。</p>
</section>

<section class="deep-section" id="limits">
  <span class="section-index">05 / LIMITS</span>
  <h2>记忆收益依赖训练与任务条件</h2>
  <p>作者有相关积累：共同一作 Karl Pertsch 的<a href="https://kpertsch.github.io/" target="_blank" rel="noreferrer">研究记录</a>包括 OpenVLA、Octo 和 FAST；更直接的证据是同体系消融与真机测试。不过每条件样本量有限，论文也没有验证跨周持续记忆或未见本体迁移。文中的试错适应使用了针对性的探索、纠错训练数据，不等于机器人无需训练便能从任意失败中学习。预训练混合机器人和视觉语言数据，公开材料不足以支持独立重现全部数据预算与结果。</p>
</section>
