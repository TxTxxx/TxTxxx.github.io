<section class="deep-section" id="problem">
  <span class="section-index">01 / PROBLEM</span>
  <h2>视频能提供预训练目标，但潜在动作不能直接执行</h2>
  <p>LAPA 将没有机器人动作标签的视频转成离散潜在动作，用于训练视觉语言模型。与 Gen2Act 在执行时读取生成视频不同，LAPA 把视频利用集中在预训练阶段，随后用真实机器人动作微调控制策略。量化阶段无需动作标签，后续潜在动作预训练仍需要视频对应的语言描述。</p>
  <p>本文由 Codex 整理，不代表个人阅读经历或独立复现。依据 <a href="https://arxiv.org/abs/2410.11758v2">2025-05-15 的 arXiv v2</a>，论文首发于 2024-10-15，已由 <a href="https://proceedings.iclr.cc/paper_files/paper/2025/hash/45d74e190008c7bff2845ffc8e3facd3-Abstract-Conference.html">ICLR 2025 正式发表</a>。团队成员 <a href="https://ai.stanford.edu/~amandlek/">Ajay Mandlekar</a>已有 RoboCasa、MimicGen 等机器人学习工作；这里的判断仍以本文对照实验为依据。</p>
</section>

<section class="deep-section" id="method">
  <span class="section-index">02 / METHOD</span>
  <h2>量化视觉变化、预测潜在动作、替换动作头</h2>
  <figure class="paper-figure">
    <a href="/images/paper-radar/2026-09-26-lapa/latent-pretraining-and-action-finetuning.png" target="_blank" rel="noreferrer"><img src="/images/paper-radar/2026-09-26-lapa/latent-pretraining-and-action-finetuning.png" alt="Figure 2 三阶段流程：两帧输入编码器得到离散 z，解码器结合初始帧重建未来；VLM 学习从图文预测 z；动作微调后输出机器人动作 a" loading="lazy" /></a>
    <figcaption>Figure 2 · <a href="https://arxiv.org/pdf/2410.11758v2#page=3">PDF 文件第 3 页</a>。Seonghyeon Ye、Joel Jang 等，<em>Latent Action Pretraining from Videos</em>，arXiv v2（2025-05-15，ICLR 2025）。依据<a href="https://arxiv.org/abs/2410.11758v2">原文许可入口</a>按 <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a> 重用；600 dpi 渲染，仅裁去图外空白与原图注，完整保留流程。点击查看高清图。</figcaption>
  </figure>
  <p>从左读起：编码器观察当前帧与未来帧，把变化压入 VQ-VAE 离散码本；解码器结合当前帧和潜在动作重建未来帧。中间阶段用编码器为视频生成伪标签，再训练 7B LWM 视觉语言模型从当前图像和指令预测这些 token。</p>
  <p>右侧是必要的动作微调。作者丢弃潜在动作预测头，换成预测真实末端增量动作的头，冻结视觉编码器、更新语言模型。它没有把某个潜在 token 固定翻译成“向左几厘米”，也不要求部署时先生成未来视频。可迁移的主要是经过预训练的表征与策略参数。</p>
</section>

<section class="deep-section" id="evidence">
  <span class="section-index">03 / EVIDENCE</span>
  <h2>平均分提升，但抓取放置没有同步领先</h2>

    <figcaption>Figure 3 · <a href="https://arxiv.org/pdf/2410.11758v2#page=7">PDF 文件第 7 页</a>。Seonghyeon Ye、Joel Jang 等，<em>Latent Action Pretraining from Videos</em>，arXiv v2（2025-05-15，ICLR 2025）。依据<a href="https://arxiv.org/abs/2410.11758v2">原文许可入口</a>按 <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a> 重用；600 dpi 裁取完整图表，保留原有误差条。纵轴虽写百分比，实际包含部分完成得分；点击放大。</figcaption>
  </figure>
  <p>先看最左边平均值，再看最右边抓取放置：Open-X 版本 LAPA 为 50.1，对照 OpenVLA 为 43.9；抓取放置却为 45.8 对 54.2。作者观察到提前闭合夹爪，说明粗粒度运动表征的收益没有解决精确抓取。</p>
  <p>这些数值来自 Franka 上三项任务，每模型共 54 次 rollout；三类泛化条件下，每任务每条件只有 6 次。<a href="https://arxiv.org/pdf/2410.11758v2#page=17">附录 B</a>允许部分得分，例如抓取放置的到达、抓住、移向水槽、完成分别为 0.25、0.5、0.75、1。因此 50.1 不是“半数任务完整成功”。</p>
  <p><a href="https://arxiv.org/pdf/2410.11758v2#page=16">Table 3</a>列出 Open-X 预训练约 97 万条轨迹，真机微调为 450 条带动作标签示范。只用人类视频预训练的版本在 Table 2 得 34.0，高于 Scratch 的 21.2，但低于 Open-X 版；它支持人机迁移的可能性，不能证明人类视频已经替代机器人数据。</p>
</section>

<section class="deep-section" id="limits">
  <span class="section-index">04 / LIMITS</span>
  <h2>骨干与微调方案不同，不能把全部收益归于动作量化</h2>
  <p>作者匹配图像分辨率和初始物体位置，但 LAPA 与 OpenVLA 使用不同 VLM 骨干、微调批量与方案。相同 LWM 骨干的 ActionVLA 是更直接的对照；Language Table 中真实动作监督仍普遍更强。论文的“30–40 倍预训练效率”还涉及 H100 与 A100 的估算换算、不同骨干和训练轮次，并非严格同硬件的端到端成本对照。</p>
  <p>潜在动作也会编码相机运动，而不只编码可控操作。第 10 页的生成式闭环展示属于定性结果，尚未验证世界模型能可靠排名策略或规划接触。<a href="https://github.com/LatentActionPretraining/LAPA">官方代码与模型权重已公开</a>，便于复核，但论文仍报告精细动作和实时推理局限。</p>
</section>
