# 界面用语

保留英文栏目名，操作提示使用简短中文；不改写文章正文或作者近况。

- Blog：作者的博客；文章页返回入口统一为「返回博客」。
- Paper Radar：按期收录的论文；历史页面用「本期」，不使用含糊的「今日」。
- 论文导读：Codex 整理的初读材料，不代表作者已读完。
- Atlas / 阅读图谱：论文收藏及公开阅读笔记；「论文收藏」不表示作者发表的论文，也不推断阅读状态。
- 演示图谱：演示数据，非个人阅读记录。
- 在 Zotero 中打开：打开本机应用中的对应条目，不是公开网页。
- 更多文章：首页推荐文章下方的列表；数量随该列表的筛选结果变化，不计上方推荐文章。
